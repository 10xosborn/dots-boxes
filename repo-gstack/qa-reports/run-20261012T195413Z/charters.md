# QA charters: design/02-materials (9b21b74)

Base: main (83e2c8b). Changed: `src/app.css` (new token blocks for all six modes: the owner's palettes; new tokens for lanes, bead dots, filters, box rims and opacity, the selected ring and glow, the board frame; backgrounds for the wood table, Neon's ambient light and the paper desk; the board surface: felt in a wood rim drawn with inset shadows and a masked `::before` ring, Neon's lit edge and glow, Paper's sheet; hover, disabled and selected states), `src/components/Board.svelte` (new `<defs>`: `dot-bead`, `fx-engrave`, `fx-emboss`, `fx-glow`, `fx-glow-soft`; the board is now one lanes path, `g.bxs` with rims and fill opacity, `g.lines`, `g.cores`, `g.dots`; input handling unchanged), `src/components/HeroBoard.svelte` (same structure), `src/lib/confetti.ts` (reads the theme's colours), `src/lib/theme/themes.ts` (blurbs, browser bar colours, swatches), `index.html` (start-up bar colours, theme-color, favicon), `src/screens/Home.svelte` (ampersand colour), textures (`grain.webp`, `paper-light.webp`, `paper-soft.webp` added; `paper-grain.webp` removed), docs.

**Surface.** Browser only (no rules, data-layer or engine change). The documented test command (`npm run test:rules`) covers Firebase rules, which this branch does not touch, so test bootstrap is skipped.

**Isolation.** Production build of 9b21b74 served by `vite preview` at http://127.0.0.1:4173/ (LOCAL; rebuilt and restarted before the run, serving `index-Dt8wCkZ1.js` and `index-DZy5Cle-.css`). Every context aborts live Firebase hosts by hostname (fonts are self-hosted), so the app runs on its local adapter and nothing reaches the live project. Throwaway browser contexts, each seeded through its own localStorage.

**Driver.** gstack's own headless Chromium through gstack's bundled playwright-core 1.62.1 (phone 390x844 with touch at 2x, desktop 1280x800 or 1920x1080 with mouse and keyboard). Aside is macOS-only (`NEEDS_ASIDE` here); the `$B` daemon restarts on this PC and can't block Firebase, so scripts drive the same Chromium directly.

**Budget.** Full (diff-aware), 900 s, gstack-qa-deadline. Probes run in risk order; anything the budget doesn't reach is reported as not run.
